## 专为弓/弩设计的刻度系统

**和平精英 爆炸猎弓 · PUBG 十字弩 · DayZ 狩猎弓 · The Forest 弓 · ARK 弓/弩**

| 痛点 | 本应用的解法 |
|---|---|
| 游戏内无法自定义刻度 | 桌面编辑器 + Overlay 覆盖层 |
| 不同距离需要不同瞄准点 | 批量生成刻度线，一组覆盖 0~250m |
| 多弹种不同弹道 | 多配置管理，Ctrl+1~4 秒切 |
| 截图校准麻烦 | 拖入截图 → 对齐刻度 → 导出预设 |
| 调整参数反反复复 | 实时 Canvas 预览，拖拽/滚轮/快捷键即时调 |

## 核心功能

### 🎨 所见即所得的编辑器

| 功能 | 说明 |
|---|---|
| **实时 Canvas** | 拖拽刻度、滚轮缩放、Ctrl+Z 撤销 |
| **水平/垂直刻度** | 任意方向（↑↓←→）、独立属性 |  
| **对称/批量** | 一键镜像 + 批量生成距离序列 |
| **配置管理** | 多配置保存/切换，Ctrl+1~9 快速调用 |

### 🎮 Overlay 游戏内覆盖模式

- `Ctrl+Shift+2` 开关透明覆盖层
- 窗口全屏、置顶、无边框、鼠标穿透
- 键盘快捷键实时调整刻度
- `Ctrl+Shift+H` 快速显示/隐藏准星

### ⌨️ 可自定义快捷键

所有操作（开关 Overlay、切换刻度、增加/减小距离、切换配置）均可自定义按键组合。

### 📤 导出

- PNG 透明图（OBS / Discord overlay）
- SVG 矢量图
- JSON 预设（分享 / 备份）
- 预设包含全部刻度、参考图、配置

## 快捷键一览

| 快捷键 | 编辑器 | Overlay 模式 |
|---|---|---|
| `Ctrl+Z` / `Ctrl+Y` | 撤销/重做 | — |
| `Ctrl+S` / `Ctrl+E` | 保存预设 / 导出 PNG | — |
| `Ctrl+Shift+2` | 打开 Overlay | 关闭 Overlay |
| `Ctrl+Shift+H` | 隐藏准星 | 显示/隐藏准星 |
| `PgUp` / `PgDn` | — | 切换选中刻度 |
| `↑` / `↓` | — | 微调距离（按住重复） |
| `[` / `]` | — | 微调线长（按住重复） |
| `Ctrl+1~9` | 切换配置 | 切换配置 |

## 快速开始

```bash
# 本地开发（浏览器预览，无需 Rust）
cd crosshair-app
npm install
npm run dev
# 打开 http://localhost:1420

# Tauri 桌面构建（需安装 Rust）
npx tauri dev      # 开发模式
npx tauri build    # 打包 exe
```
